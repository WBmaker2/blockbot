# BlockBot 업데이트 내역

## 2026-10-27

BlockBot의 첫 버전을 완성했습니다.

- 블록을 끌어다 붙여 로봇을 움직이는 코딩 화면을 만들었습니다. 앞으로, 왼쪽·오른쪽 회전, 반복, 벽 확인, 목표 확인 블록을 쓸 수 있어요.
- 5×5, 6×6 크기의 3D 로봇 세계를 만들었습니다. 벽과 목표, 로봇의 위치와 방향이 한눈에 보이고 이동과 회전이 부드럽게 이어집니다.
- 실행, 일시정지, 한 단계 실행, 초기화, 속도 조절을 넣었습니다. 지금 실행 중인 블록이 밝게 표시돼요.
- 도전 10개를 넣었습니다. 각 도전에는 힌트, 성공 설명, 기준 블록 수, 별점이 있고, 별점과 마지막으로 고른 도전은 브라우저에 저장됩니다.
- 텍스트 모드를 넣었습니다. `move`, `left`, `right`, `repeat 4 { move }`, `if wall { right } else { move }`처럼 입력할 수 있고, 한국어 낱말도 알아듣습니다. 잘못 쓴 줄 번호도 알려 줘요.
- 선생님 화면에서 도전을 골라 해답과 설명을 볼 수 있습니다. 진행 기록 초기화, 좌표·블록 강조 설정, 학습지 인쇄도 할 수 있어요.
- 키보드만으로 도전을 풀 수 있게 했습니다. 화면 읽기 프로그램을 위한 상태 안내와 실행 기록, 고대비 화면, 애니메이션 줄이기 설정도 넣었습니다.
- 휴대폰에서는 코딩/세계 탭으로 나뉘고 실행 버튼은 항상 아래에 보입니다. 태블릿과 넓은 화면에서는 두 화면을 나란히 보여 줍니다.
- 오프라인에서도 다시 열 수 있도록 설치형 웹 앱(PWA)으로 만들었습니다.
- 안전장치를 넣었습니다. 블록 코드를 직접 해석하고, 동작·실행 단계·반복·겹침 횟수에 한도를 두어 프로그램이 멈추지 않게 했습니다. `eval`이나 서버 통신은 쓰지 않습니다.
- 단위 테스트 80개, 브라우저 상호작용 테스트 10개, 접근성 자동 검사, 오프라인 재실행 확인을 모두 통과했습니다.
- 깃허브에 올리고 깃허브 페이지스로 자동 배포되도록 설정했습니다.

실행 방법:

```bash
npm install
npm run dev
```

검사 방법:

```bash
npm test
npx playwright test
npm run lint
npm run build
```
