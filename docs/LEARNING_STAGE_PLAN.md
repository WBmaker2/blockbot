# BlockBot 학습 단계 확장 계획

## 1. 목표

BlockBot을 로그인, 개인정보 입력, 백엔드 없이 개선한다. 학생이 순차 구조, 반복 구조, 선택 구조를 단계적으로 익히고, 마지막에는 세 구조를 조합해 문제를 풀 수 있게 만든다.

## 2. 지켜야 할 제약

- 로그인 없음
- 이름, 이메일, 학교 등 개인정보 입력 없음
- 서버, 데이터베이스, API 없음
- 진행 상황은 기존처럼 브라우저 `localStorage`에만 저장
- 실행 코드는 지금처럼 안전한 AST 인터프리터로만 해석
- GitHub Pages 정적 배포와 오프라인 사용 유지

## 3. 현재 학습 내용의 한계

- 도전 10개가 하나의 목록으로만 보여서 학습 순서가 드러나지 않는다.
- 순차, 반복, 선택이 어느 도전에서 시작되는지 학생이 알기 어렵다.
- 반복 안에 조건을 넣는 조합 학습이 부족하다.
- 각 도전의 학습 목표가 화면에 명시되지 않는다.
- 선생님이 단계별 진행 상황을 한눈에 보기 어렵다.

## 4. 확장할 학습 단계

도전을 5개 단계, 15개 도전으로 구성한다.

### 1단계 · 순차

여러 동작을 위에서 아래로 차례대로 실행하는 감각을 익힌다.

1. 첫걸음
2. 방향을 바꿔요
3. 두 번 꺾기

### 2단계 · 반복

같은 동작을 반복 블록으로 줄이고, 반복 안에 여러 동작을 넣는 법을 익힌다.

4. 반복의 힘
5. ㄱ자 길
6. 계단 오르기
7. 두 번 접기

### 3단계 · 선택

앞에 벽이 있는지, 목표가 있는지 확인하고 상황에 따라 다른 동작을 고른다.

8. 벽을 만나면
9. 목표를 확인해요
10. 목표를 두 번 확인해요

### 4단계 · 선택과 반복

반복 안에서 조건을 확인하고, 조건과 반복을 함께 사용한다.

11. 벽을 따라
12. 선택의 길
13. 조건을 품은 반복

### 5단계 · 종합

배운 순차, 반복, 선택을 조합해 더 긴 문제를 해결한다.

14. 마지막 미로
15. 마지막 점검

## 5. 화면 개선

### 도전 목록

- 도전을 단계별로 묶어서 보여 준다.
- 각 단계에 번호, 이름, 짧은 설명, 완료 수를 표시한다.
- 단계별 진행 막대를 표시한다.
- 현재 도전을 강조한다.

### 플레이 화면

- 도전 제목 위에 `1단계 · 순차` 같은 단계 배지를 표시한다.
- 도전 설명 아래에 해당 도전의 학습 목표를 표시한다.

### 선생님 화면

- 도전이 속한 단계와 학습 목표를 표시한다.
- 기존 해답, 설명, 힌트, 학습지 인쇄는 그대로 유지한다.

### 학습지

- 학습지에 단계와 학습 목표를 함께 출력한다.

## 6. 데이터 구조

도전 데이터에 다음 필드를 추가한다.

```json
{
  "stage": "sequence",
  "learningGoalKo": "여러 동작을 위에서 아래로 차례대로 실행할 수 있어요."
}
```

단계 정보는 별도 목록으로 관리한다.

```ts
{
  id: 'sequence',
  order: 1,
  titleKo: '순차',
  taglineKo: '위에서 아래로 차례대로',
  descriptionKo: '...',
  learningGoalKo: '...'
}
```

## 7. 구현 순서

1. 5단계 정보와 15개 도전 데이터 작성
2. 도전 목록을 단계별 그룹으로 표시
3. 플레이 화면에 단계 배지와 학습 목표 표시
4. 선생님 화면과 학습지에 단계 정보 반영
5. 모든 도전의 해답 실행 테스트 추가
6. 단계 목록, 진행 표시, 접근성 브라우저 테스트
7. 생산 빌드와 오프라인 확인

## 8. 완료 기준

- 15개 도전이 모두 참조 해답으로 목표에 도달한다.
- 모든 도전이 블록 수 기준 별점을 정상 계산한다.
- 도전 목록에서 5개 단계와 단계별 진행률이 보인다.
- 모든 도전 화면에서 단계 배지와 학습 목표가 보인다.
- 선생님 화면과 학습지에서도 단계 정보를 확인할 수 있다.
- 개인정보 입력, 로그인, 서버 호출이 없다.
- 단위 테스트, 브라우저 테스트, 접근성 검사, 생산 빌드가 통과한다.

## 9. 구현 결과 (2026-10-27)

- 5개 단계와 15개 도전을 구현했다.
- 도전 목록의 단계별 그룹과 진행률, 플레이 화면의 단계 배지와 학습 목표를 구현했다.
- 선생님 화면과 학습지에 단계와 학습 목표를 반영했다.
- 단위 테스트 96개와 브라우저 테스트 13개가 통과했다.
